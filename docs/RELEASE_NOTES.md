## Какой файл скачать

| Файл | Что это |
|---|---|
| **ZapretTG-Setup.exe** | Установщик (рекомендуется): ярлыки, автозапуск по желанию, удаление через «Приложения» |
| **ZapretTG.exe** | Один файл без установки |
| **ZapretTG-portable.zip** | Папка без установки — запускается быстрее одного exe |
| SHA256SUMS.txt | Контрольные суммы |

Установка одной командой (PowerShell): `irm https://raw.githubusercontent.com/tendo432/ZapretTG/main/scripts/install.ps1 | iex`

> Программа не меняет настройки антивируса сама. Если Защитник удалит `winws.exe` или WinDivert (известное ложное срабатывание `HackTool` для всех сборок zapret), исключить можно — по желанию — только две папки `bin` с этими файлами. Подробно: [SECURITY.md](https://github.com/tendo432/ZapretTG/blob/main/SECURITY.md).

## Что нового в 1.2.2

- **Исключения Защитника — только с вашего согласия.** В установщике галочка выключена по умолчанию, скрипт установки спрашивает, программа добавляет их только по кнопке с подтверждением. Исключаются лишь папки `bin` с `winws.exe` и WinDivert, а не вся программа.
- **Проверяемые сборки:** аттестация происхождения GitHub (`gh attestation verify`), SHA-256 и ссылки на VirusTotal у каждого файла, сведения о сборке ниже.
- **Сверка с оригиналами:** каждая сборка побайтово проверяет, что встроенные zapret-discord-youtube и tg-ws-proxy не изменены.
- Раздел безопасности: что программа меняет в системе, куда подключается, как всё вернуть.
