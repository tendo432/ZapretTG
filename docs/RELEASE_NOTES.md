## Какой файл скачать

| Файл | Что это |
|---|---|
| **ZapretTG-Setup.exe** | Установщик (рекомендуется): ярлыки, автозапуск, исключения Защитника, удаление через «Приложения» |
| **ZapretTG.exe** | Один файл без установки |
| **ZapretTG-portable.zip** | Папка без установки — запускается быстрее одного exe |
| SHA256SUMS.txt | Контрольные суммы |

Установка одной командой (PowerShell): `irm https://raw.githubusercontent.com/tendo432/ZapretTG/main/scripts/install.ps1 | iex`

> Защитник Windows может принять winws.exe/WinDivert за «HackTool» — это ложное срабатывание. Добавьте папку программы и `C:\ProgramData\ZapretTG` в исключения.

## Что нового

- **DNS для нейросетей**: ChatGPT, Claude, Gemini, Copilot, Grok — через XBox DNS / Comss.one / свой DNS; системный режим с DoH на Windows 11 или собственный DoH-сервер приложения.
- **Новый интерфейс**: полупрозрачное окно с размытием, кольцевые индикаторы, график трафика Telegram.
- **Исправлено самопроизвольное отключение** zapret и прокси: автоперезапуск после сбоев, сна и смены сети; защита от второго экземпляра; вывод winws больше не может его «подвесить».
- **Исправлены баги интерфейса**: переключатели сдвигались после клика; на маленьких экранах и при масштабе 125–150 % обрезались элементы.
- Восстановление файлов zapret после антивируса, кнопка исключений Защитника, корректное удаление (DNS, службы и автозапуск возвращаются как было).
