# Безопасность ZapretTG

ZapretTG работает с правами администратора и меняет сетевые настройки, поэтому здесь честно и полностью
описано, что программа делает, куда подключается и как проверить, что вы скачали именно то, что собрано из этого кода.

## Коротко

- **Открытый код**, собирается только автоматически в GitHub Actions — файлы релизов никто не собирает вручную.
- **Код zapret и tg-ws-proxy не изменён**: каждая сборка побайтово сверяет встроенные файлы с оригиналами ([`tools/verify_upstream.py`](tools/verify_upstream.py), коммиты — в [`UPSTREAM.json`](UPSTREAM.json)).
- **Подлинность релиза проверяется**: SHA-256 и криптографическая аттестация происхождения GitHub у каждого файла.
- **Без телеметрии**: нет аналитики, аккаунтов, отправки данных о вас.
- **Ничего не делает с антивирусом без вашего согласия.** Исключения Защитника — только по отдельной кнопке или галочке (по умолчанию выключена) и только для двух папок `bin`.
- Все изменения системы **обратимы**: выключение модуля или удаление программы возвращает всё как было.

## Почему антивирус может ругаться

`winws.exe` (zapret) использует драйвер **WinDivert** — он перехватывает сетевые пакеты, чтобы видоизменять их для обхода DPI. Так же работают GoodbyeDPI и все сборки zapret. Антивирусы помечают такие инструменты как `HackTool`/`RiskTool` — это не вирус, а категория «программа, которая может перехватывать трафик». WinDivert подписан своим разработчиком, его исходники открыты: [basil00/WinDivert](https://github.com/basil00/WinDivert).

Если Защитник удалил `winws.exe` или `WinDivert64.sys`, можно (по желанию) исключить **только** папки с этими файлами:

| Установка | Папки |
|---|---|
| Установщик / install.ps1 | `C:\Program Files\ZapretTG\_internal\resources\zapret\bin` и `C:\ProgramData\ZapretTG\zapret\bin` |
| Любая версия (кнопка в программе: «Проверка → Исключения Защитника…») | папки `bin`, которые показываются в окне подтверждения |

Удалить исключения: «Безопасность Windows → Защита от вирусов и угроз → Управление настройками → Исключения». Деинсталлятор убирает их сам.

## Как проверить скачанный файл

1. **Хеш.** В PowerShell: `Get-FileHash .\ZapretTG-Setup.exe` — сравните с таблицей SHA-256 в описании [релиза](https://github.com/tendo432/ZapretTG/releases/latest) и с файлом `SHA256SUMS.txt`.
2. **Происхождение.** С [GitHub CLI](https://cli.github.com): `gh attestation verify ZapretTG-Setup.exe --repo tendo432/ZapretTG` — подтверждает, что файл собран workflow этого репозитория из конкретного коммита и не подменён.
3. **VirusTotal.** В описании релиза есть ссылки на проверку каждого файла по хешу. Ожидаемо: несколько движков помечают WinDivert как `HackTool` (см. выше), остальные — чисто.
4. **Код без изменений.** `python tools/verify_upstream.py` — скачивает оригиналы и сравнивает каждый файл.
5. **Собрать самому:** `pip install -r requirements.txt pyinstaller` → `pyinstaller ZapretTG.spec` ([README → Сборка](README.md#сборка-из-исходников)).

## Что программа меняет в системе

Всё — только когда вы включаете соответствующую функцию:

| Что | Когда | Как вернуть |
|---|---|---|
| Драйвер WinDivert (служба `WinDivert`) | пока работает zapret | «Zapret → Удалить службы», удаление программы |
| `netsh int tcp set global timestamps=enabled` | при запуске zapret (как в оригинальном `service.bat`) | безопасная настройка TCP, на работу сети не влияет |
| Служба Windows `zapret` | режим «Служба Windows» | «Zapret → Удалить службы» |
| Задача планировщика `ZapretTG` (запуск при входе) | «Запускать вместе с Windows» | выключить переключатель, удаление программы |
| DNS сетевых адаптеров, шаблоны DoH | «DNS для нейросетей» | выключить DNS — прежние настройки сохраняются и возвращаются |
| Блок записей в `hosts` (с резервной копией `hosts.zaprettg.bak`) | кнопка «Обновить hosts» и подтверждение | «Убрать записи из hosts» |
| Исключения Защитника для папок `bin` | только кнопка/галочка с подтверждением | «Безопасность Windows → Исключения», удаление программы |
| Удаление записи автозапуска оригинального `TgWsProxy` (HKCU\…\Run) | при включении автозапуска ZapretTG — чтобы два прокси не дрались за порт | запустить оригинальный TgWsProxy и включить его автозапуск |
| Файлы `C:\ProgramData\ZapretTG` (настройки, логи, копия zapret) | всегда | удаление программы (по вопросу) |

## Куда подключается программа

ZapretTG не отправляет никаких данных о вас. Сетевые соединения:

| Куда | Зачем | Когда |
|---|---|---|
| Серверы Telegram (`*.web.telegram.org`) и Cloudflare | работа Telegram-прокси (так устроен tg-ws-proxy) | прокси включён |
| `raw.githubusercontent.com/Flowseal/tg-ws-proxy` | список CF-доменов для прокси (оригинальное поведение tg-ws-proxy) | прокси включён |
| `api.github.com`, `raw.githubusercontent.com` | проверка обновлений zapret и tg-ws-proxy | при запуске, если включено (можно выключить) |
| `raw.githubusercontent.com/Flowseal/zapret-discord-youtube` | списки ipset/hosts, обновление zapret | только по кнопке |
| Выбранный DNS-сервис (XBox DNS, Comss.one, Cloudflare, Google или ваш) | DNS-запросы | DNS включён |
| `chatgpt.com`, `claude.ai`, `grok.com`, `perplexity.ai` (`/cdn-cgi/trace`) | проверка «из какой страны вас видят» | только по кнопке «Проверить» |

Сам zapret (`winws.exe`) никуда не подключается — он меняет ваши пакеты локально.

Программа **слушает** только `127.0.0.1:1443` (Telegram-прокси; адрес и порт меняются в настройках) и, в режиме DNS «Через приложение», `127.0.0.1:53` / `[::1]:53`. Наружу из локальной сети ничего не открыто, если вы сами не укажете адрес `0.0.0.0`.

## Права администратора — зачем

Драйверу WinDivert, службам Windows, настройке DNS и планировщику нужны права администратора. Программа запрашивает их один раз через стандартное окно UAC; автозапуск через планировщик не показывает UAC при каждом входе.

## Сообщить об уязвимости

Не публикуйте уязвимости в открытых issues — используйте приватное сообщение: вкладка **Security → Report a vulnerability** в репозитории. Обычные ошибки — в [Issues](https://github.com/tendo432/ZapretTG/issues).
